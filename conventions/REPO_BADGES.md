# Repo Badges

Repositories in the UnitVectorY-Labs organization should include an appropriate set of badges in their primary README.md file above the main title.

These badges provide quick insights into various aspects of the project. This includes things like the license, project status, released version, and code coverage.

The template for badges is defined here:

https://github.com/UnitVectorY-Labs/uvy-labs-guide/blob/main/docs/_bestpractices/badges.md

## badgeindexer

The primary reason for the consistent use of badges is because of the [badgeindexer](https://github.com/UnitVectorY-Labs/badgeindexer) project run by UnitVectorY-Labs for its own repo.  This crawls and indexes the badges on all of the REAME.md files in the organization stored at [unitvectory-labs-badgeindexer](https://github.com/UnitVectorY-Labs/unitvectory-labs-badgeindexer) and browseable at https://badgeindexer.unitvectorylabs.com/
